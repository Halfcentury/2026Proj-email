# 个人课程项目功能范围

优先复用现有素材、页面组件、业务函数和接口，新功能的视觉、交互和操作习惯与现有系统保持一致。

## 保留范围

保留个人登录、Gmail／Outlook 邮件管理、邮件分析、RAG 回复、自然语言助手、自动化规则，以及日历预约、会议记录和附件处理。已有邮件整理和批量邮件操作继续使用原有实现。

邮箱及云盘授权、邮件同步、外部回调、队列和定时任务继续支撑这些功能。知识、历史邮件、回复记忆、用户写作偏好和各领域的数据模型继续复用。

本轮已实际删除下线模块及其依赖、环境变量、部署任务和测试模拟器，原来的范围开关不能恢复这些代码。数据库历史迁移和已有数据保留，少量只读类型与历史数据清理规则继续用于兼容旧记录；不会通过删除表或迁移来节省空间。

## 邮件工作区整合

继续按《AI邮件助手整合设计（完整版）》实现，复用原有阅读器、写信窗口、卡片、抽屉、邮件引擎和业务服务。

- 当前邮件增加“分析／回复／资料／操作”面板，桌面使用侧栏，窄屏使用现有抽屉。
- 邮件按钮和自然语言助手共用只读分析、完整 RAG 回复、日历、预约、会议及附件归档服务。分析不进入邮件动作执行路径。
- 资料记录实际知识条目与原文、历史邮件、回复经验、会议、日历查询和附件引用。知识引用校验真实记录及片段；资料失败明确提示，缺失业务事实列为待确认。
- 本次回复要求不写入长期偏好。AI 候选使用独立草稿会话；已有人工草稿保留。当前邮件依据统一排除草稿，避免把用户编辑内容当成新来信。
- 预约显示时间、时区、参与人及目标日历，确认后复用原预约服务并重查冲突。服务商改期失败保留原时间；取消结果未确认时提示核对日历。预约及会议增加可空来源上下文，历史记录保持兼容。
- 附件归档拆为只读建议与已确认计划执行，校验邮箱、附件内容及目录；执行不重新询问模型改选目录。低置信度待确认归档、原有纠正、移动、反馈和去重继续保留。
- 会议来源可直接打开对应记录，停用录制后仍可查看既有纪要。原有参会人隐私约束、回调和队列继续使用。

整合后全量回归：6,933 通过、155 项历史失败、1,062 跳过；与清理后基线逐项比较，没有新增失败。服务商取消状态提示修正后，106 项针对性测试通过。最终 16 项浏览器验收全部通过，并补测了取消状态未确认的前端提示。生产构建、应用代码类型检查、服务工作线程构建及结构检查通过。

验证使用隔离的本地邮箱、日历和模型模拟器。预约创建、来源关联及日历中的实际事件已核对；模拟器的改期接口返回 404，本轮验证了回滚与错误提示，正常改期路径由单元测试覆盖。真实模型质量、真实服务商及会议录制提供商端到端联调尚未验收。截图继续维护在“邮件助手功能精简验收”页面。

本轮生成的生产构建与本地测试缓存已清理，合计 7,739,588,585 字节；数据库业务数据与历史迁移保留。部署新增可空来源字段时，沿用现有迁移流程应用迁移并重新生成 Prisma 客户端、重启应用。

## 本轮差距补齐

2026-10-26，继续复用现有素材、页面组件、业务函数和接口，补齐上轮核对出的业务连接。

- 来信附件复用同一读取与正文提取方法，接入只读分析、完整 RAG 回复和助手读取工具。参考资料展示实际提取内容；来信附件与待发送附件分别进入提示词，读取失败和截断明确提示。沿用 PDF、DOCX、TXT、CSV、HTML 能力，单附件上限 10 MB，自动参考最多 4 个、每个最多 8,000 字。
- 助手可查询当前邮件关联预约、预约类型及会议。邮件面板根据邮件和补充要求准备预约方案，缺少决策时提示确认；可选时间复用原有工作时间、提前量和冲突检查。写入仍需确认。
- 聊天工具结果写入现有 `ChatMessage.parts/metadata`，邮件面板读取同一次分析和回复。预约、归档与录制设置保存执行结果；重开聊天恢复完成状态，邮件面板显示操作名称、时间和待核对信息，继续保留原业务服务的幂等约束。
- 历史邮件保留会话定位，回复经验可打开具体记录，配置附件按邮箱及来源校验后打开具体文件，来信附件可定位和高亮。
- 反馈区分一次性修改、长期写作偏好、知识、分类和规则。继续复用写作偏好和知识保存接口、分类选择组件、原规则编辑器；切换页签保留未保存输入，长期修改须确认保存。建议操作可直接打开原标签选择器或定位本面板的日程、会议、附件操作。
- 归档在上传前保存云盘上传意图；失败重试先核对已知文件或目标目录中的文件内容，唯一匹配才恢复。结果仍不明或有冲突时暂停重传，保留待核对提示。

未新增依赖。迁移 `20261026093000_filing_upload_recovery` 仅为现有 `DocumentFiling` 增加可空上传恢复元数据，不删除历史数据。部署沿用现有迁移、Prisma 客户端生成及应用重启流程。

## 入口更名与测试邮件中文化

2026-10-27（香港时间），将原“智能助手”统一更名为“自动化”，同步侧栏、命令面板、页面标题、配置引导和帮助说明。“对话”保留为自然语言入口；邮件阅读器中的“AI 助手”处理当前邮件，工具栏中打开对话的按钮标为“AI 对话”。继续使用现有组件、布局、业务函数及接口。

三组演示邮箱、Google／Outlook 浏览器测试种子和 Outlook 模拟器内置测试邮件的主题、正文、发件人显示名及相关标签已中文化；固定模型的默认模拟回复也使用中文。品牌名、邮箱地址、稳定 ID 和协议字段保持有效，相关搜索和主题匹配预期同步更新。Outlook 模拟器启动及重置后都会通过原 Graph 接口恢复中文测试邮件，复用现有模拟器，不新增依赖。
